# Alertas DAP Manager

Herramienta para registrar y consultar alertas legislativas y reportes DAP mañaneros, con filtros por tipo, categoría y mes, vista de mosaico y panel con gráficas.

## Cómo verla en GitHub Pages

1. Sube `index.html` a la raíz del repositorio.
2. Ve a **Settings → Pages**.
3. En "Build and deployment", elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`. Guarda.
5. En unos minutos, GitHub te da la URL pública (algo como `https://tu-usuario.github.io/tu-repo/`).

## Nota importante sobre los datos

Las alertas se guardan en el navegador de quien la usa (localStorage), no en el repositorio ni en un servidor. Cada persona que entre a la página tiene su propia copia local; no se comparten automáticamente entre dispositivos o personas. Usa el botón "Exportar copia (JSON)" dentro de la herramienta para respaldar o pasar los datos a otro equipo.
